--- layout: default --- {%- comment -%} COURSE & LESSON One layout, two faces, chosen by depth. A course lives at /courses// and its lessons at /courses/// — so the URL itself says which face to render, and the folder structure IS the data model. No registry of lessons to maintain: a lesson is a file in the course's folder carrying `type: lesson` and an `order:`. _courses/apex-for-admins/index.md → the course page _courses/apex-for-admins/01-intro.md → a lesson, inside the player The course face: a meta header built from front matter (level, duration, lesson count, updated), a Start button aimed at the first lesson, the curriculum, then the prose as "about this course". The lesson face: the player — video on top, prose under it, every lesson in a rail on the right with the current one marked, and prev/next pagination at the bottom. The rail collapses to a
above the content on narrow screens. {%- endcomment -%} {%- assign parts = page.url | split: '/' -%} {%- assign is_lesson = false -%} {%- if parts.size > 3 %}{% assign is_lesson = true %}{% endif -%} {%- if is_lesson -%} {%- capture course_url %}/{{ parts[1] }}/{{ parts[2] }}/{% endcapture -%} {%- assign course = site.courses | where: 'url', course_url | first -%} {%- else -%} {%- assign course = page -%} {%- assign course_url = page.url -%} {%- endif -%} {%- comment -%} The syllabus: every doc in this course's folder that calls itself a lesson, in `order:` order.
