Every lesson uses the same fictional billing system, connected a different
way, so by the end you have seen one problem solved four times and know what
each solution costs. The final lesson is the one nobody teaches and every
production integration eventually grows: the job that checks the other three
did what they claimed.

Watched best in order — each pattern is introduced by the failure of the
previous one.
