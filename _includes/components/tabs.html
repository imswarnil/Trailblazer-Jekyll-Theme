{%- comment -%} The panel-visibility rules have to be generated: CSS cannot express "the nth checked radio reveals the nth panel" without knowing n, and the radios are not siblings of the panels — they live inside the tab list, where the label needs them. So the container is queried with :has() instead. Each rule hides every panel and then shows one, which keeps the set consistent no matter which tab is checked. Where :has() is unavailable the whole block simply does not apply and the stylesheet's default — panel one visible — stands. Scoped by id, so two tab sets on the same page cannot fight. {%- endcomment -%}
